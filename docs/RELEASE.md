# Zetty Studio — vývojová verze

Samostatné streamovací studio pro Windows 10/11 x64. OBS není potřeba.

Instalátor **Zetty-Studio-0.1.1-Setup.exe** je v souborech tohoto vydání. Vytvoří zástupce Zetty Studio na ploše a v nabídce Start s vlastní ikonou Z.

- Scény a zdroje: obrazovka nebo okno, kamera, obrázky, video, text, webové zdroje a alerty.
- Zvukový mixér, místní nahrávání WebM a multistream přes RTMP/RTMPS.
- Nastavení rozlišení, FPS, datového toku a CPU/GPU enkodéru podle dostupného hardwaru.
- Připravené integrace společného chatu, počtů diváků a alertů; jejich dostupnost závisí na oprávněních poskytovatelů.

Jde o první vývojovou verzi. Přihlášení Twitch a YouTube vyžaduje nastavení OAuth aplikací. Kick chat a alerty vyžadují vlastní relay server. TikTok podporuje vysílání jen s přiděleným RTMP serverem a klíčem; jeho LIVE chat a diváci zde dostupní nejsou. Instalátor není podepsaný certifikátem vydavatele.
